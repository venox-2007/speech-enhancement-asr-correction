# Saved demonstration replay

Download and open OPEN_DEMO_BACKUP.html locally. It embeds audio and actual pipeline outputs.
It is a saved replay, not live inference. The separate JSON and WAV files contain the same saved cases.

Source audio and references: Cassia Valentini-Botinhao, University of Edinburgh (2017),
VoiceBank+DEMAND, https://doi.org/10.7488/ds/2117, CC BY 4.0.
Original excerpts were resampled to 16 kHz mono. Enhanced excerpts were additionally processed by the project's U-Net.
See ../../THIRD_PARTY_NOTICES.md.
