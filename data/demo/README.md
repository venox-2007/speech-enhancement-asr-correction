# Demonstration excerpts

These six noisy recordings and reference transcripts come from VoiceBank+DEMAND:
Cassia Valentini-Botinhao, University of Edinburgh (2017), https://doi.org/10.7488/ds/2117.
License: CC BY 4.0, https://creativecommons.org/licenses/by/4.0/.
The recordings were resampled from 48 kHz to 16 kHz mono by this project.
See ../README.md for the full dataset download and attribution.
Run `python scripts/setup_demo.py` from the project root to restore the app sample paths.
